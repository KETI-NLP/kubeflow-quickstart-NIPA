# Korean Heritage Text ShortQA Source vs Benchmark Examples

- source benchmark file: [korean_heritage_text_shortqa_benchmark.json](/workspace/kubeflow-training-snippets/VLM_SERVE_EVAL_Qwen3_5/tmp_eval_datasets/korean_heritage_text_shortqa_benchmark.json)
- 목적: 원본 QA 쌍과 benchmark용 변환 QA 쌍을 나란히 놓고 검수하기

메모:
- `원본 QA 쌍`은 `source_query`와 `source_chosen`입니다.
- `benchmark QA 쌍`은 `benchmark_question`과 `answer`입니다.
- 일부 샘플은 변환이 깔끔하고, 일부 샘플은 원문 질문과 benchmark 타깃 사이에 간극이 있어 검수가 필요합니다.
- `designation_name` 타입은 질문에 정답이 노출되는 문제가 커서 현재 최종 benchmark에서는 제외했습니다.

### 4. 무장향교대성전

원본 QA 쌍
- Q: `무장향교 창건일과 대성전 중건 연도를 알고 싶습니다.`
- A: `무장향교는 1420년(세종 2)에 창건되었고, 대성전은 1842년(헌종 8)에 중건되었습니다. 초기 건물은 전란으로 소실되었으나 조선 후기에 이르러 현재의 모습으로 복구되었습니다.`

benchmark QA 쌍
- Q: `무장향교대성전의 제작 또는 조성 시기는 언제인가?`

- 원문은 `향교 창건일`과 `대성전 중건 연도`를 함께 묻고 있어서, benchmark answer `1420년`이 대성전 기준으로는 다소 애매할 수 있습니다.
