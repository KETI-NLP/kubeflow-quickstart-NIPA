                                                                                                                                                                                                                                                                                                                                                        
 Usage: python -m lighteval accelerate [OPTIONS] MODEL_ARGS TASKS                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                                                        
 Evaluate models using accelerate and transformers as backend.                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                        
 Returns:                                                                                                                                                                                                                                                                                                                                               
 dict: Evaluation results containing metrics and scores for all tasks

[required]                                                                                                                                               │
│ *    tasks           TEXT  Comma-separated list of tasks to evaluate. Format: 'task1,task2' or 'task{|fewshot}'. Use 'lighteval tasks list' to see available tasks. [required]                                                                                                                                                                       │
